# Идентификация диктора по голосу на LibriSpeech

Учебный эксперимент по **закрытой идентификации диктора**: модель выбирает одного из заранее известных дикторов по аудиозаписи. Работа основана на курсовой Ивана Таранника и переработана в небольшой воспроизводимый скрипт.

## Данные

Используется [LibriSpeech `train-clean-100`](https://us.openslr.org/12/), исходный набор из 100 часов английской речи. Его страница указывает лицензию **CC BY 4.0**. Архив занимает около 6,3 ГБ; аудиофайлы в этот репозиторий не входят.

Скачайте `train-clean-100.tar.gz` с официальной страницы и распакуйте локально. Скрипту нужен путь к папке `train-clean-100`, содержащей подпапки с числовыми ID дикторов:

```text
data/LibriSpeech/train-clean-100/<speaker_id>/<chapter_id>/*.flac
```

В проверенном запуске использован официальный архив с MD5 `2a93770f6d5c6c964bc36631d331a522` (совпадает с [контрольной суммой OpenSLR](https://openslr.trmal.net/resources/12/md5sum.txt)).

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python src/experiment.py --data-dir data/LibriSpeech/train-clean-100 --output results.json
python -m unittest discover -s tests -v
```

По умолчанию выбираются 10 дикторов и 40 записей каждого. Параметры `--speakers`, `--per-speaker` и `--seed` позволяют изменить размер эксперимента и повторить выборку. Значение `--per-speaker` должно быть не меньше 40 и делиться на 4. Аудио остаётся на вашем компьютере.

## Методика

- Для каждой записи извлекаются 20 MFCC коэффициентов и их дельты; по времени вычисляются среднее и стандартное отклонение. Получается вектор из 80 признаков.
- Для каждого диктора выбираются четыре разные главы книги, по 10 записей из каждой. Две главы (20 записей) идут в обучение, одна (10) в валидацию и одна (10) в тест. Главы между частями не пересекаются; распределение записано в `results.json`. Масштабирование признаков выполняется только по обучающей части внутри `Pipeline`.
- Сравниваются логистическая регрессия и линейный SVM. Модель выбирается по macro F1 на валидации, после чего один раз оценивается на тесте.

**Ограничение протокола:** в обучении и тесте присутствуют те же дикторы. Поэтому результат нельзя трактовать как узнавание новых дикторов, устойчивость к шуму или биометрическую верификацию. Выборка состоит из чистой английской речи всего десяти человек.

## Результаты

Полный скрипт запущен на `train-clean-100` с `seed=42`: 200 обучающих, 100 валидационных и 100 тестовых записей. Два теста на повторяемость выбора и отсутствие пересечения глав пройдены.

| Модель | Валидация: accuracy | Валидация: macro F1 | Тест: accuracy | Тест: macro F1 |
| --- | ---: | ---: | ---: | ---: |
| Логистическая регрессия | 0,9000 | **0,8722** | 0,8800 | 0,8678 |
| Линейный SVM | 0,9000 | 0,8667 | — | — |

Тест оценён только для модели, выбранной по валидации. Полные параметры выборки и результаты сохранены в [results.json](results.json). Первоначальная схема с разделением отдельных записей давала 100% на тесте, но у каждого диктора главы пересекались между обучением и тестом; поэтому в итоговом эксперименте использовано разделение по главам.
